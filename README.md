# View

Claude Code の計画をスマホで読める日本語の HTML にまとめるプラグイン。ページ上で文章を選んで質問を残せます。

## 使い方

Claude Code **2.1.285 以降**と Python 3 が必要です。同じ応答で計画を改訂して承認を求めたとき、古い本文がフックに渡る問題が 2.1.285 で修正されました。起動前に `claude --version` で確認してください。リポジトリを取得して、計画を立てたいプロジェクトから起動します。

```sh
claude --plugin-dir /path/to/plan-viewer-plugin
```

計画を立てる前に、下記の手順でスマホから View サーバーを開けるようにします。Claude Code に計画の承認画面が出たら、そのまま待ち、View の通知に表示された `/review-….html` をスマホで開いてください。たとえばサーバーが `http://<PCのLANアドレス>:8765/` なら、その末尾に通知のファイル名を付けます。初回は PIN 入力後、同じ URL をもう一度開きます。本文を確認したら Claude Code に戻り、承認または修正を選びます。

プレビューには提出された Markdown 原文をそのまま表示します。計画を修正して再提出すると新しい URL が表示されます。プレビューは出力先に残り、不要になったものは削除できます。質問・一覧に対応する解説ページが必要なら、「Viewでまとめて」と頼めば、技術的な議論や作業のまとめもページにできます。保存先は既定で `~/plan-viewer/` です。変更するには起動前に環境変数 `PLAN_VIEWER_DIR` を設定します。

## PC・スマホで読む

Claude Code で `/view:serve` を実行し、PC のブラウザで `http://127.0.0.1:8765/` を開きます。起動時に表示される4桁の PIN を入力してください。

同じ Wi-Fi のスマホから読むには、信頼できるネットワークでサーバーに `--host 0.0.0.0` を指定し、スマホで `http://<PCのLANアドレス>:8765/` を開きます。この接続は HTTP です。LAN からは閲覧のみで、質問の保存は PC 自身または認証済みの Tailscale Serve 経由に対応します。質問は出力先の `questions.json` に保存されます。

質問を保存するには、サーバー側の Python が `os.O_NOFOLLOW`（シンボリックリンクをたどらずにファイルを開く機能）を提供している必要があります。非対応環境でもページを閲覧できます。質問を投稿すると HTTP 501 と保存できない理由が返ります。

## 開発時の確認

```sh
claude plugin validate .
python3 -m unittest discover -s scripts -p 'test_*.py'
```
